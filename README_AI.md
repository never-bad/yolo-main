# 🤖 AI 预标注（智能标注）功能说明

本文档介绍 YOLO 训练平台内置的 **AI 智能预标注**功能。该功能基于大模型实现文本驱动的自动目标检测与分割，可将人工标注时间从「逐张框选」缩短为「一键批量生成 + 人工审核」，大幅提升标注效率。

## 功能简介

AI 预标注是标注页面（`/annotate`）中的一项核心能力：选择一张图片后，只需输入类别名（如 `person, car, helmet`），系统即可自动识别图中目标并生成对应的边界框，覆盖到现有标注画布上，供人工审核与微调。

支持 **单图 AI 预标注** 与 **整批批量预标注** 两种模式，批量任务在后台异步执行，可实时查看进度并随时停止。

---

## 技术原理

AI 预标注采用「**YOLO-World 文本驱动检测 + SAM 分割精修**」的两阶段方案：

1. **文本驱动检测（YOLO-World）**
   使用 `yolov8s-world.pt` 开放词汇检测模型。通过 `set_classes()` 将类别名作为文本提示注入模型，无需针对每个类别重新训练，即可检测任意指定类别。

2. **分割精修（SAM）**
   使用 `sam_b.pt`（Segment Anything Model）。对 YOLO-World 输出的每个候选框做精细分割，再取分割掩码的最小外接矩形作为最终框，得到更贴合目标边界的标注结果。

3. **结果兼容**
   最终输出的 BBox 与现有标注体系完全兼容（`{class_id, x1, y1, x2, y2}`），可直接保存、导出为 YOLO 格式或用于后续训练。

> 若 `sam_enabled` 关闭，则跳过 SAM 精修，直接使用 YOLO-World 的检测框。

## 功能特性

- ✅ **单图 AI 预标注** - 对当前图片即时生成标注框
- ✅ **批量预标注** - 对任务内全部图片后台异步标注，实时进度推送
- ✅ **随时停止** - 批量任务可一键取消，已标注结果保留
- ✅ **增量标注** - 只补标注缺失类别，不覆盖已有的人工标注（详见[增量标注逻辑](#增量标注逻辑)）
- ✅ **中文类别支持** - 内置中英映射表，自动将中文类别转为英文提示词，显著提升识别率
- ✅ **置信度可调** - 标注前可设置置信度阈值，控制检出框的严格程度
- ✅ **模型单例缓存** - 检测器与分割器只加载一次，批量标注高效
- ✅ **配置可热更新** - 检测器、SAM、置信度、设备等均可通过 API 动态调整

## 快速上手

### 前置条件

- 已安装 ultralytics（含 YOLO-World 与 SAM）
- 已安装 `clip` 模块（YOLO-World 的 `set_classes()` 依赖），若缺失会导致预标注报错
- 已下载模型权重文件（见[模型文件与目录](#模型文件与目录)）

### 模型文件位置

将以下权重放入 `backend/models/sam/` 目录：

| 文件 | 用途 |
| --- | --- |
| `yolov8s-world.pt` | YOLO-World 文本驱动检测器 |
| `sam_b.pt` | SAM 分割精修模型 |

## 使用流程

### 第一步：准备数据集

在「数据集」页面上传 ZIP 并执行「准备」，使数据集状态变为 `prepared`。

> 未准备的数据集无法创建标注任务。

### 第二步：创建标注任务

1. 进入「标注」页面（`/annotate`）
2. 以卡片方式选择已准备的数据集
3. 在「类别」输入框填写类别（逗号分隔，如 `person,car,安全帽`）
   - 留空时系统会自动读取 `data.yaml` / `classes.txt` / `coco.names` 中的类别
4. 点击「创建任务」

### 第三步：单图 AI 预标注

1. 在任务画布中选中一张图片
2. 点击工具栏「AI 预标注」按钮
3. 可调整「置信度」后再次标注
4. 系统自动生成检测框，人工审核、微调后点击「保存」

### 第四步：批量 AI 预标注（推荐）

1. 在标注面板点击「批量预标注」按钮
2. 确认提示后，后台开始对全部图片进行智能标注
3. 顶部工具栏实时显示进度（`已完成/总数`）与进度条
4. 可点击「停止」按钮随时取消
5. 完成后展示本次标注的图片数量，进入人工审核阶段

## 配置说明

AI 预标注的默认配置（保存在 `backend/data/sam_config.json`）：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `detector` | `yolo_world` | 检测器类型，`yolo_world` 或 `none` |
| `detector_weights` | `yolov8s-world.pt` | 检测器权重文件名 |
| `sam_enabled` | `true` | 是否启用 SAM 分割精修 |
| `sam_weights` | `sam_b.pt` | SAM 权重文件名 |
| `imgsz` | `640` | 检测器输入尺寸 |
| `sam_imgsz` | `1024` | SAM 输入尺寸 |
| `conf` | `0.25` | 默认置信度阈值 |
| `half` | `false` | 是否启用半精度（省显存） |
| `device` | `auto` | 运行设备：`auto` / `cpu` / GPU 索引 |

可通过 `GET /sam/config` 查看、`POST /sam/config` 修改配置。

## 中英文类别映射优化

YOLO-World 的 CLIP 文本编码器主要面向英文，直接使用中文类别名会导致识别率偏低。为此前端内置了一张 **中英映射表**（`CLASS_EN_MAP`），覆盖 `person`、`car`、`helmet`、`truck`、`traffic light` 等常见类别：

- 标注时用户仍填写中文（如 `安全帽`）
- 前端自动转换为英文提示词传给后端（如 `helmet`）
- class_id 索引仍与全局类别一一对应，标注结果无偏差

因此，即使类别是中文，AI 预标注也能获得较高的命中率。常见内置映射举例如下：

| 中文 | 英文 | 中文 | 英文 |
| --- | --- | --- | --- |
| 人 / 行人 | person | 车 / 汽车 | car |
| 安全帽 / 头盔 | helmet | 卡车 / 货车 | truck |
| 红绿灯 | traffic light | 摩托车 / 电动车 | motorcycle |
| 手机 / 手机架 | cell phone | 背包 / 书包 | backpack |

## 增量标注逻辑

批量预标注采用「**按缺失类别增量标注**」策略，避免破坏人工标注：

1. 对每张图片先读取其**已有标注**，得到已标注的类别集合。
2. 计算本次待标注类别中**尚未标注**的类别索引（缺失类别）。
3. 若该图所有类别都已标注，则直接跳过。
4. 只对缺失类别执行检测，并**追加**其检测框；已有框原样保留。

这样既能自动补全新类别，又不会覆盖或重复人工已标注的内容。

## API 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/sam/available` | 检查预标注可用性（模型是否可加载） |
| GET | `/sam/config` | 读取配置 |
| POST | `/sam/config` | 更新配置 |
| POST | `/sam/validate` | 校验模型有效性 |
| POST | `/sam/auto-label` | 单图预标注 |
| POST | `/sam/batch/start` | 启动批量预标注 |
| GET | `/sam/batch/{batch_id}` | 查询批量任务进度 |
| POST | `/sam/batch/{batch_id}/stop` | 取消批量任务 |

### 单图预标注示例

```bash
curl -X POST http://localhost:8000/sam/auto-label \
  -H "Content-Type: application/json" \
  -d '{
    "task_id": "task_20260115_123456",
    "image_id": "img_001",
    "classes": ["人", "车"]
  }'
```

> `prompts` 字段可选，用于与 `classes` 一一对应的英文提示词，可进一步提升中文识别率。

### 批量预标注示例

```bash
curl -X POST http://localhost:8000/sam/batch/start \
  -H "Content-Type: application/json" \
  -d '{
    "task_id": "task_20260115_123456",
    "classes": ["人", "车"]
  }'
```

返回 `batch_id` 后，轮询 `GET /sam/batch/{batch_id}` 即可获取进度。

## 常见问题

**Q1：点击 AI 预标注报错/失败？**
- 确认已安装 `clip` 模块（YOLO-World 的 `set_classes()` 需要）。
- 确认 `yolov8s-world.pt` 与 `sam_b.pt` 已放入 `backend/models/sam/`。
- 首次加载模型较慢（尤其是 CPU），属正常现象，可稍后再试。

**Q2：中文类别识别率低？**
- 使用的是内置中英映射的提示词，若你的类别不在映射表内，可补充 `CLASS_EN_MAP` 映射，或直接使用英文类别名。

**Q3：批量预标注提示「未检测到目标」？**
- 可调低置信度阈值后重试。

**Q4：批量预标注到一半能否停止？**
- 可以，点击「停止」按钮即可取消，已标注的结果会保留。
