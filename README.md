# 🚀 YOLO 训练平台（模型守门员版）

基于 YOLOv8 + FastAPI + Vue3 的自动化目标检测模型训练平台。本分支（`feature/model-gatekeeper`）在 `main` 分支基础上，引入了 **模型守门员（Model Gatekeeper）** 机制与多项训练体验优化，目标是把平台从"能训练"升级为"能自动保证模型越换越好"的轻量级 MLOps 平台。

---

## 相对 main 分支新增的功能

### 1. 🛡️ 模型守门员（Model Gatekeeper）—— 核心新特性

训练产出新的 `best.pt` 后自动触发新旧模型对比，杜绝"越训越差"的模型污染生产环境：

- **自动拉取基准**：从模型仓库自动选取**同一业务、版本最高**的上一代生产模型（`production_ready`）作为对比基准，无需人工指定
- **统一评估集**：优先使用数据集自带的独立测试集 `test`（黄金测试集），无 `test` 时回退验证集 `val`
- **多维判定**（三个维度同时满足才晋升）：
  - 整体精度：新模型 `mAP50-95` 必须**严格大于**旧模型
  - 防偏科 / 防灾难性遗忘：逐类别 AP 相对跌幅 > 5% 即判定"关键类别退化"，拦截晋升
  - 推理性能：记录新旧模型 FPS / 单张推理耗时，写入评估报告供参考
- **晋升 / 淘汰 / 首版**：
  - 通过 → 存入模型仓库、版本号 +0.1 递增、标记 `production_ready`
  - 未通过 → 归档为 `rejected` 失败实验，不更新仓库，旧模型继续服役，生成中文诊断报告（哪些类别退化）
  - 首版（无同业务生产基准）→ 自动直接晋升 `v1.0`，不阻断首训流程
- **人工强制覆盖（Override）**：高级工程师可对被拦截的模型强制设为生产版本（记录原因，自动退役旧生产版本）
- **血缘管理**：每个模型附带 `lineage` 元数据（父模型、基座模型、数据集、任务），版本可追溯
- **基座模型原则**：微调任务只用上一代同业务 `best.pt` 作基座，杜绝跨业务/劣化模型继续训练

### 2. 🏷️ 业务场景自动识别

- 按数据集类别标签（中英文关键词）**自动推断业务类型**（缺陷检测 / 行人 / 车辆 / 包裹等），无需手动选择
- 业务字段贯穿训练任务与模型仓库，作为守门员隔离对比与版本递增的依据

### 3. ⚙️ 训练参数自动推荐（新手友好 / 专家可调）

- 选中数据集与模型后，按训练环境**自动推荐**最优训练参数：轮次、图片尺寸、批次、学习率、优化器、权重衰减、早停耐心值
- 高级参数（学习率 / 优化器 / 权重衰减 / 早停机制）默认展开，支持手动调整
- 用户未输入时按训练环境自动配置合理默认值（微调 vs 全新训练默认参数不同）

### 4. 🖥️ 训练节点选择

- 创建任务时可选训练 GPU 节点，默认为「自动选择（推荐）」
- 后端自动检测可用 GPU 列表

### 5. 🛑 早停机制体验优化

- 支持设置早停耐心值（patience），模型学不动时自动停止，保护精度、节省资源
- 早停触发时任务状态标记为**「已完成（早停）」**而非失败，UI 有明确徽章

### 6. 🔧 训练稳定性大幅提升（容器 / 服务器环境）

- AMP 混合精度自检失败 → 自动降级 FP32 重试，不再莫名失败
- 容器环境强制单进程数据加载（workers=0），避免多进程死锁
- 批次自适应归一化（batch=-1/0 → 按显存给安全值）
- 启动提速：首次 AMP 失败后全局跳过自检；启动阶段输出"正在加载深度学习环境"提示
- 失败原因客户化提示（可读原因 + 操作步骤弹窗）+ 一键「重新训练」复用原参数

### 7. 📊 训练进度体验

- 训练任务卡进度条加入**百分比**显示
- 任务卡展示守门员结果徽章（生产就绪 ✅ / 已淘汰 ❌）与诊断报告折叠面板

### 8. 📦 模型仓库管理增强

- 模型列表展示状态（`production_ready` / `rejected`）、版本号、业务类型、血缘信息
- 新增接口：`GET /models/production?business=` 查询生产模型、`POST /models/{id}/override` 强制覆盖
- 模型注册自动记录 `gatekeeper` 完整评估报告

### 9. 🗑️ 功能调整

- 移除「图片推理 / 视频推理」模块（暂时不使用），保留模型上传 / 导出、数据集管理、AI 预标注等基础能力

### 10. 🐳 部署方式重构为单镜像

- Docker 部署由"前后端多镜像"重构为**单镜像**（Nginx + Uvicorn + supervisor 一体），一键构建推送，`docker compose up` 即可运行，数据独立挂载卷（升级不丢数据集）

## 技术栈

- 后端：Python 3.11 · FastAPI · Ultralytics YOLOv8 · PyTorch
- 前端：Vue 3 · Vite · TypeScript · Element Plus
- 部署：Docker 单镜像（Nginx + Uvicorn + Supervisor）

## 快速开始

```bash
# 单镜像构建并启动
cd docker
docker compose up -d --build
```

训练完成任务后，可在「模型管理」页查看守门员判定结果与晋升/淘汰状态。
