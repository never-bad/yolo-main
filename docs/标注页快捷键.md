## 0. 生效前提（先读这条，否则会以为快捷键坏了）

快捷键在下列任一情况**不响应**，这是设计如此：

| 情况 | 原因 |
| --- | --- |
| 焦点在输入框 / 文本域 / 下拉框里（`INPUT` `TEXTAREA` `SELECT`） | 避免打字时误触发；重点场景：左上角**图片名搜索框**、类别筛选下拉 |
| 还没进入某个标注任务（无 `currentTask`） | 建任务页上没有可操作的画布 |
| 正在加载某张图的标注（`loadingAnnotation`） | 防止翻页途中改到上一张的数据 |
| 弹窗（`GlobalDialog`）里输入时 | 弹窗自己处理 `Enter` 确认 / `Esc` 取消，见「弹窗内」一节 |

`Ctrl`/`Cmd` 组合键命中后**直接 return**，不再走单键分支——所以 `Ctrl+S`、`Cmd+S` 这类组合键不会顺带触发 `S` 之外的行为。

## 1. 已实现的快捷键

### 1.1 保存与撤销/重做

| 键位 | 作用 | 说明 |
| --- | --- | --- |
| `Ctrl+S` / `Cmd+S` | 保存当前图片的标注 | 已拦截浏览器默认保存页；按钮 `title` 同步提示，L462 |
| `Ctrl+Z` / `Cmd+Z` | 撤销上一步（含撤销刚落地的抠图框、`C` 清空的整批框） | 每图独立的历史栈，最多 50 步；**切到别的图片会换一套栈**，回不来跨图的编辑 |
| `Ctrl+Shift+Z` / `Ctrl+Y`（含 `Cmd` 变体） | 重做 = 把刚撤销掉的那一步**再放回来**（反撤销） | 只有按过 `Ctrl+Z` 之后才有意义；做过任何新的编辑动作，重做栈立即清空、撤销不回来 |

> `Ctrl+C` 复制**没有**被拦截，走浏览器原生复制，不受本页快捷键影响。

### 1.2 图片浏览（跟随筛选 + 搜索结果）

| 键位 | 作用 | 说明 |
| --- | --- | --- |
| `→` / `D` / `d` | 下一张 | 只在**当前筛选条件 ∩ 文件名搜索结果**里移动；到最后一张即停住，不会跳到列表外的图 |
| `←` / `A` / `a` | 上一张 | 同上；游标显示在侧栏图片列表下方（`第 n / m 张`） |

> 侧栏的「上一张 / 下一张」按钮已移除，翻页入口只有画布两侧的 `‹ ›` 和上面这对键盘键位。

### 1.3 删除

| 键位 | 作用 | 风险 |
| --- | --- | --- |
| `Delete` / `Backspace` | 删除**当前选中的标注框**（未选中框时无动作） | 可 `Ctrl+Z` 撤销 |
| `C` / `c` | **一键清空当前图片的所有标注框**（矩形框 + 分割轮廓一起清，图片本身不删） | 可 `Ctrl+Z` 一次整体撤销；本来就没框时只提示、不产生历史 |
| `X` / `x` | 删除**当前图片**（连同其标注文件与同名标签文件） | ⚠ **不弹确认、不可恢复**；批量标注进行中也能删 |

> `C` 清空后会自动触发保存（与其他编辑动作一致的 1.5s 自动保存），所以**离开页面前不用手动 `Ctrl+S`**；但要留着 `Ctrl+Z` 的话，别在清空后再做别的编辑（会占掉撤销栈顶）。

### 1.4 模式进出与确认

| 键位 | 作用 | 说明 |
| --- | --- | --- |
| `G` / `g` | 进入 / 退出**智能抠图**模式 | 工具条上刻意不放按钮，只有这个键；进入时会互斥关掉描轮廓模式和框选交互区域模式 |
| `E` / `e` | 开关**边缘增强叠加层** | 青色细线显形 Sobel 强梯度（水陆过渡带、纹理恢复线），配合规范 v1.3 §1.6 的 B/C 类模糊边界判边；等同工具条「边缘」按钮 |
| `S` / `s` | 开关**顶点吸附** | 落点/拖点自动贴到半径内最强边缘（A/B 类 ±2px）；C 类不可见边界按物理线索画时建议关闭；等同工具条「吸附」按钮。`Ctrl/Cmd+S` 保存优先命中，不受影响 |
| `Enter` | 抠图模式：**落定当前目标**，下一次左键开一个新目标（无点位时等于退出抠图）<br>描轮廓模式：**闭合当前轮廓**并生成一条分割标注 | 非上述模式时无动作 |
| `Esc` | **分层退出**，一次只退一层，按代码顺序为：<br>① 退出抠图模式 → ② 丢弃"按下待判定"的拖拽（还没判定是改拐点还是平移）→<br>③ 取消绘制中的轮廓 → ④ 退出描轮廓模式 → ⑤ 退出交互式框选区域 | 退出抠图会撤掉还没算完的任务，已落地的框用 `Ctrl+Z` 撤销 |

### 1.5 视图（缩放 / 平移 / 复位）

| 操作 | 键位 | 作用 |
| --- | --- | --- |
| 滚轮缩放 | 鼠标滚轮（非键盘） | 以**光标位置**为中心放大 / 缩小，缩放比限制在 0.05 ~ 20 倍 |
| **复位视图** | `F` / `f` | **恢复图片大小**：缩放比回到"整张图适配窗口"并居中（`fitView`）。推荐用法——描轮廓 / 抠图时左键被落点占用，双击可能被误吞或触发绘制，复位一律按 `F` |
| 双击复位 | 双击画布（非键盘） | 同 `F`（`fitView`，L1670）<br>⚠ 例外：抠图模式下双击 = 换下一个目标（等同 `Enter`），不复位视图；描轮廓**有草稿点**时双击 = 误触吞掉，不复位视图 |
| 按住平移 | `空格` + 左键拖拽 | 平移视图；`空格` 是唯一需要"按住"的键（`keydown` 置位、`keyup` 复位） |
| 放大 / 缩小按钮 | **无键盘键位** | 画幅工具条上的 `+` / `−`（L282-L283），以画布中心缩放 |

> `+` `-` `0`（复位）目前**没有**绑定键盘键位，这三个键也未被占用；将来若要加，须同步登记到本节与第 4 节占用表。

## 3. 鼠标操作（对照用，视图类见 1.5）

| 操作 | 作用 |
| --- | --- |
| 空白处左键拖拽 | 画矩形框 |
| 拖住框体 / 拖角点 | 整体移动框 / 缩放框 |
| 分割目标：拖白色拐点 / 拖轮廓内部 / 拖边上空心圆 | 改拐点 / 整体平移 / 新增拐点；右键点顶点 = 删除该顶点 |
| 抠图模式：左键点目标内部 | 排队抠轮廓，点完可立刻点下一个，甚至切图，结果各回各图 |
| 抠图模式：已落地目标上继续左键 | 补点微调（沿用该目标原本的类别） |
| 抠图模式：连续左键点多个位置 | **智能连通判断**：后端对每个前景点单独出掩码，按"掩码互相包含"做并查集分组 —— 落在同一片连通区域的点自动合并成一个闭合区域（一个框）；互不相连的点自动拆成多个框（最新点击的那片并入当前目标，其余另起新标注）。前端把前景点按点击顺序虚线串联作实时预览 |
| 抠图模式：右键**拖框** | **区域擦除**：拖一个矩形把抠多了那块（文字水印/相邻水面）整块挖掉，毫秒级、不走 SAM；挖断成多块时自动拆成多条标注，挖没了就删框，`Ctrl+Z` 可撤销 |
| 抠图模式：右键**点一下**（不拖） | 抠掉那个点（负点微调，走 SAM 重描） |
| 描轮廓：点回起点 | 与 `Enter` 等效的闭合方式（需 ≥3 点） |
| 描轮廓：点更早的顶点 | 用"该顶点→最新点"这段闭合；该段 >5 点才生效，点数不足只提示并**保留草稿**（不误删） |
| 描轮廓：右键 | 删除**点到的那个**顶点；没点到具体顶点则删最后一个。**不清空整条草稿**。绘制中双击一律忽略（不复位、不闭合） |

## 5. 新增快捷键的规矩

1. **只改一处**：所有画布键位统一进 `handleKeydown`（L3195），需要"按住"语义的再加 `handleKeyup`。不要再往组件上散落 `@keydown`。
2. **必须放在第 0 节的 guard 之后**：沿用 `INPUT/TEXTAREA/SELECT` 与 `loadingAnnotation` 判断，别绕过。
3. **有模式的键位要判断当前模式**，并且保持互斥：抠图 / 描轮廓 / 框选交互区域三者不能同时生效（参考 `toggleCutoutMode` L2251 的互斥清理）。
4. **`Esc` 永远只做"退一层"**，新增模式时按现有分层顺序插入自己的分支，不要让 `Esc` 一次退出所有状态。
5. **破坏性操作要三思**：像 `X` 那样不弹确认的删除键位，除非有明确批量场景需求，否则一律要求确认弹窗或保证可 `Ctrl+Z` 撤销。
6. **命中即 `e.preventDefault()`**，避免滚到页面底部、触发浏览器快捷行为。
7. **UI 上留提示**：涉及按钮的加 `title="快捷键 …"`（参考 L462、L469）；纯键盘入口在 `.view-hint` 文案里补一句（参考 L280）。
8. **回来更新本文档**：第 1 节对应小节加行（视图类进 1.5）+ 第 4 节占用表改状态 + 第 6 节加一条变更记录。三处缺一处即为漏更。
9. **验证**：`npx vue-tsc --noEmit` 通过之外，必须**在浏览器里真按一次**（注意：焦点在搜索框时快捷键不响应，先点画布再测）。
