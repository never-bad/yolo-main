### 2.8 容器内代码是否热更新（部署必读）

`docker-compose.yml` 只挂载三个卷：

```
${DATA_DIR:-yolo-data}   → /app/data
${RUNS_DIR:-yolo-runs}   → /app/runs
${MODELS_DIR:-yolo-models} → /app/models
```

**`/app/backend/src` 不在挂载列表里。** 因此：

- 改 `backend/src/**`、`frontend/src/**` → **必须重建镜像**（`docker/build_push.sh`），`scp` 到服务器再 `docker restart` 无效
- 改 `backend/data/**`、`backend/models/**`、`runs/**` → 挂宿主目录（`DATA_DIR=/opt/yolo-data`）即可直接生效
