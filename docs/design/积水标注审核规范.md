# 积水分割标注审核规范 v1.3

适用算法库：积水（jishui，model_20260916_103722 / jishui_v0 系列）
配套工具：`audit_annotations.py`（自动审核）、`fix_draft_annotations.py`（AI 草稿自动修复）
审核对象：`backend/data/datasets/<ds>/annotations/*.json`

> **v1.1 修订（2026-09-28 实图反馈）**：废弃 v1.0 的"镜面反射必要"判据——暗光下大面积水体常无反光，按旧规则会系统性漏标（见 §1.2 图三案例）。新增漏标/过标判定依据（§1.3）与参考标注处理原则（§1.4）。

> **v1.3 修订（2026-09-29）**：针对"边界模糊、需要人工猜测"的场景，新增边界四分类判据（§1.6）、误差允许范围（D6）与一致性自检（D7），并补充验收指标。核心原则：**一致性优先于绝对正确**——猜测边界统一画在过渡带中线，允许偏移量按模糊程度分档。

## 一、语义标准（决定"该不该标、标多大"）

### 1.1 积水正样本判据（同时满足两条）

| 编号 | 判据 | 量化定义 |
|---|---|---|
| S1 | 是连续水体 | 区域内为**积水本体**（含无光的暗水、浑浊浅水），不要求有镜面反光；反光只是水面的**辅助线索**，不是准入条件 |
| S2 | 有面积与深度 | 图上连通面积 ≥ 400 px²（约 20×20 cm @ 1080p），目视可没过鞋底；薄水膜、潮湿地面不算 |
| S3 | 边界可闭合 | 能沿"水体↔地面"过渡带画出闭合轮廓；模糊时取过渡带中线 |

- **不确定时不标**；但"看不清是不是水"≠"没有反光就不是水"——判断依据是**整体场景**（水洼形态、低洼积水逻辑、周围干湿对比），不是单看有没有亮斑。
- 全图无积水 → 标为**空白负样本**（`sample_type=background`，不画框）。负样本是压制误检的关键。
- 干砖、井盖、格栅、阴影、车灯直射亮斑 → 不标，即使颜色发暗。

### 1.2 标注范围界定（图一/图二案例）

**亮色反光区 ≠ 积水范围**。暗光场景中，水面只有受光部分显亮，背光部分发暗但仍是水：

- 标注范围 = **整个水体**（亮区 + 与之连续的暗区），边界画在水体与地面的过渡带；
- 禁止只描亮斑（系统性漏标），也禁止把亮斑周围的潮湿地面一并圈入（系统性过标）；
- 判别技巧：顺着亮斑向暗处追，**地面纹理消失、出现连续平滑质感**的地方就是水体真实边界；纹理仍在（碎石、砖缝、泥沙颗粒）则为地面。

### 1.3 漏标与过标判定依据（图三/图四/图五案例）

| 类型 | 特征 | 修法 |
|---|---|---|
| **漏标**（图三） | 图中存在明显水体但无框；或框只圈了水面一部分（通常漏掉暗区、遮挡物后方、与主水面相连的小水湾） | 补画完整水体轮廓；同一连通水面**合为一框**，不因遮挡物碎片化 |
| **过标**（图四） | 框覆盖了无水的机械、泥地、格栅；多个独立水洼被一个大框连成一片；框边缘压在干地上 | 按水陆过渡带收缩边界；**被物体隔开的独立水面拆成多框**，框不跨越干地/机械 |
| **正确**（图五） | 每块独立水面一框，边界贴合水陆过渡带，暗水与亮水都包含，干地、机械、格栅在框外 | 以此为基准对齐手感 |

**量化辅助判据**（审核脚本可加）：框内区域与"平滑水面质感"的匹配度——对框内做局部方差滤波，方差高（纹理重=地面/机械）占比 >40% 提示过标；框外紧邻带若存在大面积低方差（平滑=水）区，提示漏标。

### 1.4 参考标注的处理原则

- **一切已有标注（含平台草稿、他人手标、AI 生成）均为参考，不是答案**：精细度不足是常态，审核时必须重新对照原图界定边界，不得直接照抄通过；
- AI 草稿（source=ai）：作为"位置提示 + 轮廓起点"，边界以人工对照 §1.2/§1.3 判定为准；
- 人工参考标注（如本轮图五）：只采纳其**范围意向**（哪里是水、分几块），顶点位置仍需逐点校；
- 冲突处理：参考标注与判据矛盾时，**以判据为准**，并把矛盾案例记入 §六 迭代记录。

### 1.5 灰区判定：浅水膜 vs 积水（v1.2 新增，2026-09-29 实图反馈）

雨后整幅路面平铺一层薄水膜（无反光汇聚、无边界形态、仅整体发暗）判为**"湿路"，不标**；出现下列任一特征才按积水标注：

| 特征 | 说明 | 标法 |
|---|---|---|
| **辙槽水线** | 轮胎辙槽/低洼槽内连续反光的水带 | 只标水线本身（沿槽的细长轮廓），不标槽外湿路 |
| **汇聚反光池** | 局部凹陷处反光明亮、有"水面感"的小池 | 按 §1.2 标整个水体（亮区+连续暗区） |
| **明暗边界水体** | 有可辨识边界形态（岸线感）的水体 | 边界画在过渡带 |

- 介于两者之间拿不准的：**标**（"宁多勿漏"只适用于**有边界形态的水体**，不适用于整幅湿路——整幅湿路误标会淹没正负样本平衡，模型会把"雨后正常湿路"全报成积水）。
- 判据口诀：**"平铺无界是湿路，有线有池才算水"**。
- 与 S2 的关系：S2"薄水膜不算"是本条的总则，本条给出可操作的三个放行特征。

### 1.6 边界模糊度四分类与判边操作指南（v1.3 新增）

标注前先给每段边界定类型，不同类型用不同判边方法，**不允许统一"凭感觉"**：

| 类型 | 视觉特征 | 判边操作 | 最大允许偏移 |
|---|---|---|---|
| **A 硬边界** | 水面↔干地纹理突变，可见清晰水线/岸线 | 贴纹理突变线画 | ±2px |
| **B 渐变边界** | 湿痕渐淡，存在 5–20px 过渡带 | **中线原则**：画在过渡带中间 | ±5px |
| **C 不可见边界** | 水膜均匀延伸至画外/被遮挡，无纹理线索 | 借物理线索推断：路缘石走向、排水沟/低洼线、阴影边界、轮胎辙印延伸方向；推断不出按 D 类处理 | ±10px |
| **D 反光干扰** | 亮斑≠水边界，或水面反光与湿地反光混杂 | 顺亮斑向暗处追（§1.2 技巧），按追到的实际过渡带归入 A/B/C | 按归类型 |

**中线原则（一致性核心）**：猜测边界一律画在过渡带中线。单人重复标注可能偏 ±5px，但"都偏中线"使标注间的系统性偏差归零——模型学到的是稳定规律而不是某个人的习惯。**一致性优先于绝对正确**：范围性错误（漏标/过标）才真正伤模型，边界 3px 抖动只是噪声（对 mAP50 影响 <0.01）。

**C 类备注要求**：按推断线索画的边界，在标注 note/审核记录中写明依据（如"沿路缘石推断"），供后续复查与规则迭代。

**典型模糊案例分析**（对照精标图）：
- 案例①暗光通道反光池（2026-09-29 实图）：中央强反光 + 四周连续平滑暗区 → D 类归 B：以亮斑为起点向暗处追，整片平滑暗区入框，边界画在水体与地面过渡带中线；禁止只圈亮斑。
- 案例②整幅浅水膜平铺路面（2026-09-29 实图）：无反光汇聚、无边界形态 → §1.5 判湿路不标；辙槽水线若连续可单独标水线（A 类贴线）。
- 案例③水面被格栅/杂物隔断：可见块独立成框（D2），隔断处的边界按 B 类中线画。

## 二、几何标准（决定"标得对不对"）

自动审核脚本逐条量化判定，**任一不达标即退回修改**：

| 编号 | 规则 | 量化阈值 | 判定方式 |
|---|---|---|---|
| G1 | 禁止矩形框 | 4 顶点且轴对齐（容差 2px）→ 不合格 | 顶点坐标差 |
| G2 | 禁止长直边 | 最长边 > max(35px, 周长×12%) → 不合格 | 边长统计 |
| G2-例外 | 图像边缘可直 | 边两端点均在图像边界上 → 豁免 G2 | 端点位置 |
| G3 | 框间不重叠 | 任意两框交集 > 4px² → 不合格 | mask 栅格求交 |
| G4 | 不自交 | 任意两非相邻边相交 → 不合格 | 线段跨立试验 |
| G5 | 不越界 | 顶点超出图像范围 > 1px → 不合格 | 坐标范围 |
| G6 | 无碎片 | 面积 < 400px² → 删除（同 S2） | mask 面积 |
| G7 | 顶点密度 | 单框 ≤ 150 点（可拖拽）；> 150 触发重抽 | 顶点计数 |
| G8 | 轮廓保真 | 简化后与原 mask IoU ≥ 0.95，否则不简化 | mask 重建 IoU |

**G7/G8 冲突时优先 G8**：边界准确性 > 编辑便利性。宁要 260 个准点，不要 60 个切掉边界的点。

## 三、绘制标准（决定"好不好用"）

| 编号 | 规则 |
|---|---|
| D1 | 边界取"水陆过渡带中线"，不刻意贴清晰处（会把湿痕圈进来） |
| D2 | 水面被遮挡物断开 → 每块可见水面独立成框，不连成大框 |
| D3 | 水流出画面 → 边界沿图像边缘闭合（G2 豁免） |
| D4 | 同场景连续帧规则一致：首帧定标准，后续帧复制微调，不逐帧重判 |
| D5 | 顶点沿边界等弧长分布（约 10px 一点），弯处自然密、直处自然疏 |
| D6 | **误差允许范围**（v1.3）：边界偏移按 §1.6 分类执行——A 类 ±2px、B 类 ±5px、C 类 ±10px。审核时偏移在允许范围内的**不判错、不返工**；超出才修。禁止为追 A 类精度把 B/C 类边界"猜"到清晰处（会把湿痕圈进来，违反 D1） |
| D7 | **一致性自检**（v1.3）：每轮抽 5 张典型模糊图隔 1 天重标，同一人两次结果 IoU 应 ≥0.90（A 类）/≥0.85（B/C 类）；不达标说明判据含糊，修订 §1.6 而不是怪标注 |

## 四、审核流程

```
AI 草稿生成（jishui_v0 出框 → SAM 重描 → 后处理抽稀）
   ↓
自动修复  fix_draft_annotations.py
   （丢矩形兜底 / 裁重叠 / 删碎片 / 重抽过密；只动 source=ai，人工标注不碰）
   ↓
自动审核  audit_annotations.py
   → 输出 G1-G8 违规清单
   ↓
人工审核（平台）
   重点看：面积最大的框（易过标含湿痕/机械）、暗光图（易只标亮斑=漏标，见 §1.2）、
   无检出图（判负样本 or 补画）、多框图（独立水面是否错误相连，见 §1.3）
   ↓
标记 reviewed=true 入库
```

**人工审核抽查比例**：
- AI 草稿来源：全看过一遍（微调成本低）
- 纯人工标注：按 20% 抽样，抽中图整组返工
- 同场景组：只要 1 帧不合格，整组复查（D4 一致性）

## 五、量化验收指标

| 指标 | 目标 | 计算 |
|---|---|---|
| 几何违规率 | 0% | 违规框数 / 总框数 |
| 人工修正率 | ≤ 30% | 被改动的 AI 草稿框 / AI 框总数 |
| 平均顶点数 | 40–120 | 单框顶点均值 |
| 负样本占比 | ≥ 5% | 背景图 / 总图 |
| 边界偏移达标率 | ≥ 90% | 落在 D6 允许偏移内的边界段 / 抽检总段数（v1.3） |
| 重标一致性 IoU | A≥0.90 / B、C≥0.85 | D7 自检结果（v1.3） |
| mask mAP50-95 | 逐轮提升 | 训练验证集指标（验证集标签须先按本规范精修） |

## 六、规范迭代机制

本规范 v1.0 的阈值来自 2026-09-28 对 140 张 / 312 框的实测标定：

| 阈值 | 来源 | 复核条件 |
|---|---|---|
| 400px² 最小面积 | 现有碎片框面积分布下界 | 若出现"小而真实的水洼"被误删 → 下调 |
| 35px / 12% 直边 | 矩形兜底框边长 200–500px，合法短边 <30px，取中间断层 | 若人工标注频繁违规 → 放宽至 50px |
| 150 顶点上限 | 前端拖拽交互实测可用上限约 200 | 若前端优化 → 上调 |
| IoU 0.95 | 0.98 时简化失败率过高（G7 无法达成） | 稳定后回调至 0.97 |

**迭代规则**：每轮训练后统计"人工修正率"与误删/误留案例，任一指标偏离目标 >10% 即修订对应阈值并升版本号，变更记录追加到本节。

**变更记录**：
- v1.1（2026-09-28）：废弃"镜面反射必要"判据（暗光水体无反光导致系统性漏标，图三案例）；新增 §1.2 亮区≠水体、§1.3 漏标/过标判定表、§1.4 参考标注处理原则；审核重点同步更新。
- v1.2（2026-09-29）：新增 §1.5 灰区判定"浅水膜 vs 积水"（平铺无界是湿路，有线有池才算水），明确"宁多勿漏"适用边界。
- v1.3（2026-09-29）：新增 §1.6 边界模糊度四分类（A 硬/B 渐变/C 不可见/D 反光干扰）与判边操作指南、中线原则、典型模糊案例；新增 D6 误差允许范围（±2/±5/±10px 分档，范围内不返工）、D7 一致性自检；§五 验收指标补边界偏移达标率与重标一致性 IoU。配套计划：前端"边缘增强叠加层 + 顶点边缘吸附"工具（待种子精标完成后实现）。
